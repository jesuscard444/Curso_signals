# Curso Signals

Plataforma web de laboratorios virtuales y recursos para la asignatura **Análisis de Señales** del programa de Ingeniería Eléctrica de la Universidad Tecnológica de Pereira.

## Contenido inicial

- Página principal responsive.
- Ruta temática del curso.
- Seis módulos de laboratorio.
- Accesos a Google Colab, Python y al repositorio.
- Estructura preparada para añadir guías, notebooks y recursos descargables.

## Estructura

```text
Curso_signals/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
└── README.md
```

## Publicar con GitHub Pages

1. Abrir `Settings` en el repositorio.
2. Entrar a `Pages`.
3. En `Build and deployment`, seleccionar `Deploy from a branch`.
4. Elegir la rama `main` y la carpeta `/ (root)`.
5. Guardar los cambios.

La página quedará disponible en:

`https://jesuscard444.github.io/Curso_signals/`
